    mull isn't installed on this PC

    mull rewrites highlighted text and types what you say, using your own AI key. Install it on the PC to use this page.

    1. Install mull and its dependencies (Arch shown; other distros are in the mull README): 
      sudo pacman -S go wl-clipboard libnotify rofi pipewire wtype
git clone https://github.com/silky-x0/mull ~/mull && cd ~/mull
go build -o ~/.local/bin/mull ./cmd/mull
ln -s "$PWD"/scripts/mull-* ~/.local/bin/
mkdir -p ~/.config/mull && cp .env.example ~/.config/mull/.env
    2. Add a free Groq key from console.groq.com/keys after GROQ_API_KEY= in ~/.config/mull/.env.
